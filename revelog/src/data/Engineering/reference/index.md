## Reference Site

### Mobbin
[사이트 이동하기](https://mobbin.com/)
- 실제 운영하고 있는 서비스들의 UI/UX 확인 가능
- MCP 제공, 실제 사용 시 구독형 결제 필요

### 21st.dev 
[사이트 이동하기](https://21st.dev/)
- 최신 UI/UX 컴포넌트등의 디자인을 참고할 수 있음 (버튼, 네비게이션 등)
- REACT 라이브러리 기준의 예시 코드 제공

### UIverse
[사이트 이동하기](https://uiverse.io/)
- 개인 프론트엔드 개발자들이 다양한 컴포넌트들을 애니메이션과 함께 업로드 및 코드 제공
- 커뮤니티 개념으로 되어있는 사이트이기 때문에 결제 필요성이 낮음
