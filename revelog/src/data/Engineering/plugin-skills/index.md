## Codex Plugin
> 초기 프로젝트 기획 시 Product Design -> UI/UX Pro (선택) -> Taste Skill (선택) -> Build Web Apps 순서로 세팅 추천

> 프로토타입 생성 -> 디자인 시스템 및 UX 검토 -> 디자인 완성도 향상 -> 실제 프로젝트 구현 순서

> Codex 앱으로 프로젝트 구현 시 `@` 을 사용하여 단계적으로 플러그인 사용 권장

### Product Design
- 실제 코드 구현보다는 **설계 -> 시안 비교 -> UX 검토 -> 프로토타입** 구현 가능
- PM 으로 **여러 디자인 시안을 만들고 선택한 시안의 프로토타입을 제작**하는데 유용

<예시 프롬프트>
```
Vue 3 기반의 시스템 모니터링 관리자 웹페이지를 개발하려고 합니다.

주요 기능은 CPU, Memory, Disk 모니터링, 서버 상태 조회, 로그 검색입니다.

먼저 사용자 동선을 설계하고 최신 SaaS 관리자 대시보드 디자인을 참고해 3가지 UI 시안을 제안해주세요.

선택한 디자인으로 데스크톱과 모바일에서 동작하는 인터랙티브 프로토타입을 구현해주세요.
```

```
(프로토타입 생성 후)
A 디자인으로 결정할게. 
이 디자인을 기준으로 대시보드, 서버 상세조회, 로그 검색 페이지를 인터랙티브 프로토타입으로 구현해줘. 
검색과 모달, 사이드바 인터랙션도 확인할 수 있도록 만들어줘.
```

### Build Web Apps
- Claude Code skills의 Frontend Design과 유사한 기능
- **반복적이고 획일화된 디자인을 피하고 코드를 구현**한 다음 브라우저 검증까지 완료 가능
- 기본적으로 해당 플러그인으로 기본 디자인은 가능하지만 **차별화된 디자인(시각적 개성, 애니메이션 등)이 필요**하다면 Taste Skill 플러그인 사용

<예시 프롬프트>
```
Build Web Apps 플러그인을 활용하여 현재 확정된 프로토타입을 실제 웹 애플리케이션으로 구현해주세요.

기술 스택:
- Vue 3 + TypeScript + Vite
- Vue Router + Pinia
- CSS Variables 기반 디자인 토큰
- Playwright E2E 테스트

요구사항:
1. docs/ 문서와 기존 프로토타입을 구현 기준으로 사용 (UI/UX Pro 에서 생성한 md 파일 문서)
2. Feature-based 폴더 구조 적용
3. Sidebar, Header, Table, Modal, Chart를 공통화
4. 처음에는 Mock 데이터를 활용하여 UI 기능 구현
5. 추후 REST API 연동이 가능하도록 코드 구조 설계
6. 데스크톱 및 모바일 반응형 구현
7. 개발 서버에서 실제 화면을 확인하고 오류 수정

디자인을 임의로 다시 생성하지 말고 확정된 디자인에 맞게 구현해주세요.
우선 프로젝트 초기 설정과 핵심 레이아웃부터 구현해주세요.
```

### Figma
- Figma 디자인을 코드로 구현, 디자인 시스템 연동 가능

## Claude Code Skills

### Frontend Design
- 일반적으로 AI 코드 생성에서는 비슷한 색, 카드 형식 레이아웃, 버튼을 반복 사용하는데 **이러한 획일적 디자인을 피하도록 유도**
- **사용자 요구에 맞는 디자인 컨셉 설정, 색상 팔레트 / 타이포그래피 / 레이아웃 설계**
- 디자인 계획을 먼저 설정 후 코드 생성 로직

### UI/UX Pro (Codex 에서 동일하게 사용 가능)
- 디자인 참고 자료와 UX 규칙을 활용해 어떠한 서비스를 구축할 것인지 제시하면 디자인 규칙을 제시해준다
- 각 개선사항 규칙들을 **md 파일 형식으로 생성해주도록 요구**하는 것이 유용

<사용법>
- 아직 공식 Codex 앱에서 설치를 지원하지 않아 프로젝트 내의 터미널을 통해 설치

```
1. cd 명령어를 통해 작업 프로젝트 디렉터리로 이동

2.  npx ui-ux-pro-max-cli init --ai codex 입력

3. 해당 경로에 정상적으로 설치가 되었는지 확인
project/
└── .agents/
    └── skills/
        └── ui-ux-pro-max/
            ├── SKILL.md
            ├── data/
            └── scripts/

4. 프롬프트를 이용해 사용
```

<예시 프롬프트>
```
UI/UX Pro Max 스킬을 활용해 현재 확정된 프로토타입을 검토해주세요.

테이블 가독성, 사용자 동선, 검색 필터, 버튼 상태, 모달 접근성, 반응형 레이아웃을 분석해주세요.

디자인 토큰(색상, 폰트, 간격, 반경), 공통 컴포넌트 기준, UX 개선 사항을 문서로 정리해주세요.

전체 디자인을 새로 만들지 말고 기존 디자인을 유지하면서 필요한 개선 사항만 제안해주세요.
```

### Taste Skill (Codex 에서 동일하게 사용 가능)
- AI가 만든 화면이 반복적인 형태가 되지 않도록 브라우저를 실행해서 검증하여 **디자인의 개성을 강화**하도록 유도
- 실제 이미지 자료를 사용, 애니메이션 및 인터렉션 강도 설정, 화면에 배치되는 정보의 밀도 설정

<예시 프롬프트>
```
Taste Skill을 활용해 현재 프로토타입을 검토해줘. 
기존 디자인 시스템과 사용자 동선은 유지하면서 타이포그래피, 레이아웃, 인터랙션의 완성도를 높여줘. 
변경이 필요한 부분만 제안하고, 변경 전후를 브라우저에서 비교해줘.
```
