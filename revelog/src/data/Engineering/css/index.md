## Layout

### display
- `display: flex` : 요소들이 기본적으로 **가로로 배치**된다. ex) `Sidebar`

### flex-shrink
- `flex-shrink: 0` : 화면을 줄여도 해당 요소의 너비는 줄이지 않는다. 

### flex
- `flex: 1` : 나머지 부분을 모두 채운다. 

### flex-direction
- `flex-direction: column;` : 요소들을 세로로 배치 (기본값 row)
