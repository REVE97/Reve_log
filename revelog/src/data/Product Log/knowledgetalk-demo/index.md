# 회고
>**개발 기간** : _2026.01.05 ~ 2026.01.15_

>처음 회사에 입사하여 Vue3 프로젝트로 **Knowledgetalk SDK** 개발 요구사항 명세서를 이용하여
**WebRTC 웹서비스**를 구현해보는 개발을 진행하였다.

>문제점 : 개발 요구사항 명세서대로 개발을 진행해보는 것이 처음이라 명세서를 보고 각 변수, 상수 상태 관리나 함수사용, 타입 설정, 요청 처리에 대한 진행사항에 어려움을 겪었고 기능 구현에만 집중하다 보니 코드리뷰를 하였을 때 어플리케이션을 실행했을 때 실제 함수들이 실행되는 과정과 메서드들을 이해하지 못하고 코드를 작성하여 코드리뷰에 대한 피드백을 많이 받았다.

>피드백 : 앞으로 개발을 진행할 때에는 함수 사용에 대한 정확한 이해를 가지고 함수를 만들고 **코드가 어떠한 플로우로 진행되는 지 설명**할 수 있을 정도로 기능 구현 뿐만 아니라 코드 분석, CS 공부 또한 놓지 말아야 겠다는 생각을 하였다.
