## Intro

처음 개발자로 업무를 시작하면서 담당했던 프로젝트와 사이드 프로젝트를
한곳에 정리할 수 있는 개인 웹페이지가 필요하다고 느꼈다.

처음에는 경력기술서와 포트폴리오를 보여주는 페이지로 시작했다.
이후 기존 플랫폼에 작성하던 개발일지와 TIL도 함께 관리할 수 있도록
Engineering과 Product Log 페이지를 추가했다.

구현한 결과뿐 아니라 학습하고 문제를 해결한 과정까지
같은 사이트에 기록하는 것을 목표로 하고 있다.

## 주요 기능

- **Resume**: 경력, 기술 스택, 실무 프로젝트, 학력과 자격증 정리
- **Side Project**: 사이드 프로젝트의 소개, 주요 기능, 구현 내용과 이미지 정리
- **Engineering**: TIL, 트러블슈팅, 기술 분석 기록
- **Product Log**: 프로젝트별 개발일지, 피드백, 회고 기록

경력기술서와 사이드 프로젝트는 A4 문서 너비로 미리 볼 수 있으며,
브라우저 인쇄 기능을 이용해 PDF로 저장할 수 있다.

Engineering과 Product Log에서는 제목·본문·태그로 글을 검색하고,
유형별로 필터링할 수 있다. Product Log에는 프로젝트 필터도 제공한다.

## 기술 구성과 역할

- **Vue 3**: 화면과 공통 컴포넌트 구성, 검색·필터 상태 처리
- **Vue Router**: 페이지 이동과 글별 상세 주소 구성
- **Vite**: 개발 서버, 빌드, Markdown·이미지 파일 자동 수집
- **yaml**: Markdown 상단의 제목·날짜·분류 등 메타데이터 해석
- **markdown-it**: Markdown 본문을 HTML로 변환
- **highlight.js**: 코드 블록의 문법 강조

## Markdown 기반 글 관리

글을 추가할 때마다 Vue 컴포넌트를 수정하지 않도록
글 데이터와 화면을 분리했다.

Engineering 또는 Product Log 디렉터리 아래에 글별 폴더를 만들고,
Markdown 파일 하나와 관련 이미지를 함께 저장한다.

Vite의 import.meta.glob으로 파일을 수집하고,
메타데이터를 읽어 목록과 상세 페이지를 구성한다.

이 구조에서는 글을 별도로 목록이나 라우터에 등록할 필요가 없다.
다만 배포된 사이트에 변경 내용을 반영하려면 다시 빌드하고 배포해야 한다.

## UI/UX를 정리한 과정

기능을 추가한 뒤에는 화면에 필요한 정보와 조작을 다시 검토했다.

- 필터 초기화 버튼 제거
- 사이드바와 검색 아이콘을 SVG 파일로 분리해 관리

현재도 실제로 글을 작성하고 읽는 과정에서
불편한 부분을 확인하며 UI/UX를 조정하고 있다.
