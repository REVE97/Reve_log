## Intro

> 처음 개발을 시작하게 된 계기는 React 라이브러리에 대해 공부하면서 실제 적용해보고 실제 일상에서 사용할 서비스를 구상하고 있었는데 취미 생활로 하고 있는 밴드 활동에서 기존 서비스들의 불편함이나 개선사항등이 떠올라 이를 해결할 수 있고 직접 커스텀할 수 있는 밴드 활동 다이어리를 만들게 되었다.
회사 업무와 병행해서 하고 있기 때문에 천천히 지속적인 업데이트 예정이다.

## 주요 기능

>밴드 활동중 필요한 **연습 사진·영상 보관** / **밴드 합주실 위치 · 주변 맛집 정보** / **합주 연습곡 악보 파일 보관** / **일정 관리** / **공지사항 및 메모** 확인 등을 스마트폰의 갤러리 / 지도 / 악보어플 / 메신저 단톡방을 일일히 실행하여 검색하지 않고 하나의 어플리케이션으로 관리 가능한 어플리케이션

## 개발 목표

- React 라이브러리를 활용한 최신 기술 경험 및 테스트를 위한 개인 프로젝트 추가
- AI 시대의 LLM을 이용한 챗봇 기능 테스트
- 프론트엔드 배포 및 API 서버 · Cloud DB 구축 경험 => Supabase(PostgreSQL 기반)

## 기능 테스트

1. 모니터링 환경 추가 - **Microsoft Clarity**
- 사용자가 애플리케이션에서 어떻게 활동하는지 체크할 수 있는 모니터링 기능

2. **Supabase 플랫폼을 활용**하여 사용자 로그인, 데이터 호출, 데이터 생성 등을 구현

3. **카카오맵 API 라이브러리**를 활용하여 사용자가 장소명 검색후 등록하면 데이터에 맞는 지도 출력

4. 밴드 일정 캘린더 페이지를 위해 **FullCalendar 라이브러리** 테스트 중

5. Supabase Storage 효율성을 위해 비디오 파일 -> 오디오 파일 변환 하기 위한 **`FFmpeg` 라이브러리** 추가
